## 1. 목적

2025년 8월, 한국산 수입품에 15% 상호관세가 적용되고(8/7) 미국 소액면세가 모든 국가에 대해 중단됐다(8/29).
이 프로젝트는 **공개 데이터만으로** 그 전후의 K-뷰티 대미 수입 변화를 측정하고, 변화의 원인 후보를 검증 가능한 방식으로 가려내며,
그 결과를 실무 의사결정으로 연결한다.

### 1.1 독자와 결정

주 독자는 **미국 현지 창고에 재고를 두고 판매하는 K-뷰티 중견 브랜드의 SCM 담당자**다. 분석은 그가 내리는 세 가지 결정에 답하도록 설계한다.

| 결정 | 분석이 줄 답 |
|---|---|
| 보충 운송수단(해상·항공) | 운송수단별 물량·단가 추세, 구조 변화 이후의 예측과 불확실성 |
| 하역 거점(서부·동부·걸프) | 권역별 해상 리드타임, 하역항 집중도와 중단 위험 |
| 안전재고 수준 | 리드타임 분포와 변동성을 반영한 거점별 재고 일수 |

### 1.2 성공 기준

- 분석을 검토하는 사람이 던질 세 가지 질문에 **데이터로** 답할 수 있다.
  1. "한국만의 변화인가, 미국 화장품 수입 전체의 변화인가?" → 국가 비교
  2. "통계에 새로 잡힌 소포인가, 실제 물류 변화인가?" → 한국 수출 통계와의 미러 분석
  3. "그래서 담당자는 무엇을 결정하나?" → 운송수단·거점·안전재고 수치화
- 누구나 원본 데이터에서 같은 숫자를 다시 만들 수 있다(네트워크 없이).
- 결론마다 근거의 강도와 한계가 함께 적혀 있다.

## 2. 질문

### 2.1 측정 (무엇이 달라졌나)

| # | 질문 | 주 지표 |
|---|---|---|
| M1 | 금액과 물량 중 무엇이 늘었나 | 12개월 수입 금액, 해상+항공 중량 |
| M2 | kg당 단가는 왜 변했나 (품목 구성 vs 품목 내 단가) | 운송수단별 USD/kg, HS10 기준 분해 |
| M3 | 어떤 품목이 성장을 이끌었나 | 품목군별 12개월 금액 변화 |
| M4 | 어디로 들어오나 | 하역 권역 비중, 하역항 집중도(HHI) |
| M5 | 해상 리드타임은 얼마인가 | 권역별 부산 출항 → 미국 입항 신고 일수 |

### 2.2 원인 검증 (왜 달라졌나) — 사전 등록 대상

| # | 질문 | 방법 |
|---|---|---|
| Q1 | 변화가 **한국 특유**인가 | 8개국 비교: 이중차분, 합성 통제, 시간 × 국가 위약 |
| Q2 | 항공 변화가 **측정 범위 변화**(소액면세 소포의 통계 편입)인가 | 한국 수출(관세청) 대 미국 수입(Census) 미러 분석 |
| Q3 | 단가 변화 중 **환율** 몫은 얼마인가 | 원화 기준 단가로의 항등식 분해 |
| Q4 | 더 세분된 세목으로 보면 **구성 효과**가 커지는가 | 한국 HSK 10단위(3304.99 하위 4개 세목) 분해 |
| Q5 | 정책 후 **해상 리드타임**이 달라졌나 | 권역별 정책 전후 중앙값 차이, 부트스트랩 신뢰구간 |

판정 기준, 비교국 선정 규칙, 다중비교 보정은 데이터를 받기 전에 [사전 등록](preregistration.md)에 고정한다.

### 2.3 예측과 결정

| # | 질문 | 방법 |
|---|---|---|
| F1 | 월 수입을 얼마나 정확히 예측할 수 있나 | 품목 × 운송수단 계층 예측, rolling-origin 백테스트 |
| F2 | 예측의 불확실성은 얼마인가 | 경험적·conformal 예측 구간과 실제 포함률 |
| F3 | 공개 전에 고정한 예측은 맞았나 | 2026-09~11 예측을 미리 고정하고 공개 후 채점 |
| F4 | 한국 수출 통계로 미국 수입을 먼저 알 수 있나 | nowcasting(한국 통계가 약 3주 빨리 공개됨) |
| D1 | 거점·운송수단 선택이 재고에 주는 영향은 | 리드타임 분포 기반 안전재고 시나리오 |
| D2 | 하역항 집중의 위험은 얼마인가 | LA·롱비치 중단 시나리오의 영향 물량 |

## 3. 데이터

원천은 7개, 기관은 5곳(미국 Census, 미국 CBP, 해양수산부, 관세청, Federal Reserve Board)이다(환율은 2026-11-06 FRED 경유에서 Board 직접 수집으로 전환, `docs/experiments/fred_to_federal_reserve_board.md`). CF-1400과 PORT-MIS는 공통 식별자가 없어 호출부호·선박명으로
선박 단위로 연결한 관측치 한 파일로 쓴다. 수집 단계에서 함께 받은 PMSA 컨테이너 체류시간과 BTS 항공화물 통계는 이 분석에 쓰지 않는다.

| 원천 | 내용 | 단위·기간 | 접근 |
|---|---|---|---|
| [Census `imports/hs`](https://api.census.gov/data/timeseries/intltrade/imports/hs.html) | 한국산 HS 3303·3304·3305·3307 수입액, 해상·항공 금액·중량 | HS10 × 월, 2024-01~2026-08 | 무료 API 키 |
| [Census `imports/porths`](https://api.census.gov/data/timeseries/intltrade/imports/porths.html) | 하역항별 수입액, 해상·컨테이너·항공 | 하역항 × HS6 × 월 | 무료 API 키 |
| [Census `imports/hs`](https://api.census.gov/data/timeseries/intltrade/imports/hs.html) (비교국) | 비교 8개국의 같은 품목 수입 | HS10 × 월 | 무료 API 키 |
| [CBP CF-1400](https://www.cbp.gov/document/report/cf-1400-record-vessel-foreign-trade-entrances) | 미국 입항 항구, 신고일, 직전 외국항 | 선박 1회 입항, 2024-04~2026-10 | CBP 주간 PDF |
| [해양수산부 PORT-MIS](https://www.data.go.kr/data/15006353/openapi.do) | 부산항 출항 일시, 다음 기항지, 호출부호 | 선박 1회 출항 | data.go.kr API |
| [관세청 품목별 국가별 수출입실적(GW)](https://www.data.go.kr/data/15100475/openapi.do) | 한국 → 미국 수출 금액(FOB)·중량 | HSK10 × 월, 2024-01~ | data.go.kr API(1회 조회 1년 이내) |
| [Federal Reserve Board G.5](https://www.federalreserve.gov/releases/h10/current/default.htm) (릴리스 XML, 7개 통화; 2026-11-06 이전에는 FRED EXKOUS 외 6개 시리즈로 수집) | 7개 통화의 월평균 환율 | 월 | 키 불필요 |

알려진 제약과 대응:
- 소액면세 화물은 Census 공식 통계에 포함되지 않는다 → Q2 미러 분석으로 직접 검증한다.
- 관세청 API의 품목 필터는 한국 HSK 코드만 받는다 → 월별 전체 품목을 받아 화장품 세목만 남긴다.
- CF-1400 신고일은 CBP가 공식 정의를 공개하지 않는다 → 리드타임은 '입항 신고까지'로 명시한다.
- 스킨케어와 선크림은 미국 HS10에서 한 세목(3304995000)으로 묶인다 → Q4에서 한국 측 세목으로 다시 나눈다.

## 4. 아키텍처와 재현성

```
data/raw (API 응답 원문) ─▶ pipeline/ (오프라인 재추출) ─▶ data/extracted ─▶ warehouse/ (dbt + DuckDB) ─▶ src/kbeauty ─▶ notebooks · reports
```

| 원칙 | 구현 |
|---|---|
| 원문 보관 | 모든 API 응답을 수정 없이 저장(관세청 XML은 gzip). manifest에 키를 뺀 요청 URL, 수집 시각, SHA-256 |
| 해시 고정 | `data/SHA256SUMS`(LF 줄바꿈, 표준 `sha256sum -c` 호환). `.gitattributes`로 데이터 파일의 줄바꿈 변환 금지 |
| 오프라인 재현 | 모든 수집기에 `--offline`. 보관 원문만으로 다시 만든 CSV가 저장본과 바이트 단위로 같아야 한다 |
| 데이터 테스트 | dbt: 하역항 합계 = 전국 합계(1달러 단위), 월 연속성, 패널 균형, 환율 커버리지, 키 유일성, 값 범위 |
| 코드 테스트 | pytest: 분해 항등식, 위약 검정, 예측의 미래 정보 차단, 합성 통제 가중치 복원, 평행 추세 검정, 파이프라인 통합 |
| 일치 확인 | 각 분석 노트북 마지막 셀이 노트북 추정치와 `scripts/run_all.py` 결과 표의 일치를 assert |
| 결과 표 재현 | 같은 환경에서는 바이트 단위 일치(`scripts/compare_tables.py --exact`). 다른 OS에서는 숫자 열을 허용 오차(rtol 1e-6, atol 1e-9)로, 문자 열은 그대로 비교한다 |
| 자동 검증(CI) | GitHub Actions(Linux): `uv sync --frozen` → pytest → `run_all`(dbt 테스트 통과 수/전체 수 출력) → 표 허용 오차 비교 |
| 날짜 설정 | `src/kbeauty/paths.py` 한 곳. 수집 범위만 월별 갱신 대상이고, 분석 날짜(사전 등록)는 고정 |
| 비밀 관리 | API 키는 `.env`에만 둔다(git 제외). 코드와 manifest에 키를 남기지 않는다 |

한 번의 명령으로 전 과정을 재현한다: `uv run python scripts/run_all.py` (해시 검증 → 오프라인 재추출 → dbt build → 표·그림).

## 5. 분석 설계

### 5.1 측정 (M1~M5)
- 비교 창: 정책 전후 **같은 계절의 12개월**(2024.09~2025.08 vs 2025.09~2026.08).
- 단가 분해: ΔUV = 구성(mix) + 품목 내 단가(price) + 상호작용. 세 부분의 합이 총변화와 정확히 같아야 한다(단위 테스트).
- 하역항 집중도: 해상 금액 기준 HHI, LA·롱비치 비중, 권역 비중.
- 리드타임: 권역별 중앙값과 p10·p90, 부트스트랩 신뢰구간, 권역 간 차이.

### 5.2 정책 전후 비교 (한국 단독)
- 계절성 제거를 위해 전년 동월 대비 로그 성장률(YoY)을 쓰고, 정책 전후 평균 차이를 OLS + Newey-West 표준오차로 추정한다.
- 13개 후보 전환 시점에 같은 통계량을 계산하는 시간 위약으로 순위를 매긴다.
- 한국 단독 비교는 다른 동시 요인을 배제하지 못하므로, 원인 판단은 5.3~5.6에서 한다.

### 5.3 국가 비교 (Q1)
- 비교국: 2024년 미국의 HS 3304 수입액 상위 8개국(집계 코드·한국 제외). 육로 비중이 큰 국가는 해상·항공 지표에서 제외한다.
- 이중차분: YoY 패널에 국가·월 고정효과, 한국 × 정책 후 더미, 환율 YoY 통제.
- 전제 확인: 평행 추세(선행 F 검정, 정책 전 추세 이탈). 위반한 지표는 이중차분 해석에서 제외한다.
- 추론: 처리군이 하나이므로 시간 × 국가 위약 순위(randomization inference). Holm·BH 다중비교 보정.
- 검정력: 위약 분포로 최소 검출 효과(MDE)를 계산하고, 그보다 작은 추정치는 "판정 불가"로 쓴다.
- 합성 통제: 정책 전 적합도(RMSPE), 가중치 쏠림, 국가 위약 순위를 함께 보고한다.
- 강건성: 비교국 구성(개별 국가 제외·추가), 정책 시점(±1개월), 환율 통제 유무.

### 5.4 미러 분석 (Q2)
- 월별 '미국 수입 / 한국 수출' 비율을 금액·중량 기준으로 계산한다.
- 기준을 맞춘다: 품목 범위(HS 33 세목 정의), 가격 기준(FOB vs 미국 관세 가격), 해상 운송 시차(0~1개월 시차 상관).
- 판정: 정책 후 비율이 유의하게 오르면 측정 범위 가설을 지지한다. 변하지 않으면 운송 방식 전환 쪽 근거로 기록한다.
- 외부 집계(식약처 대미 수출 14.5억 달러, 2026 상반기)와 미국 측 수입(약 10.8억 달러)의 차이를 항목별로 설명한다.

### 5.5 환율 분해 (Q3)
- Δlog(USD/kg) = Δlog(KRW/kg) − Δlog(KRW per USD). 원화 기준으로 단가 분해를 다시 하고 환율 몫을 분리한다.

### 5.6 한국 세목 분해 (Q4)
- 관세청 HSK 10단위(3304.99 하위 4개 세목 포함)로 단가를 다시 분해하고, 미국 측 분해 결과와 비교한다. 세목 이름은 관세청 응답 원문의 품목명(`statKor`)에서 뽑는다(`pipeline/build_hsk_names.py`).

### 5.7 예측 (F1~F4)

| 항목 | 설계 |
|---|---|
| 대상 | 전체 금액·중량, 품목군 4개(스킨케어·메이크업·헤어·기타) × 운송수단 2개 |
| 범위 | 공개 수입통계의 예측(외부 시장 흐름 지표). 기업 내부 판매·재고·발주 데이터를 쓰는 수요예측이 아니다 |
| 통계 모델 | 직전 값, 작년 같은 달, 작년 같은 달 × 성장률, ETS(감쇠 추세·계절), SARIMAX(환율·정책 더미) |
| 머신러닝 | 하위 8개 시계열을 함께 학습하는 전역 모델 9종: Ridge, Elastic Net, kNN, Random Forest, Extra Trees, Gradient Boosting, LightGBM, XGBoost, MLP. 모델별 하이퍼파라미터와 목표(로그 수준·로그 변화)·특징 묶음을 함께 조정(76개 설정) |
| 모델 선택 | 기준 시점마다 이미 관측된 마지막 3개월로 검증해 고른다(nested rolling origin, 시험 달은 보지 않음). 선택 절차 자체의 표본 외 성적(`ml_selected`)을 보고하고, 표본 외 순열 중요도로 해석 |
| 계층 | bottom-up과 MinT 정합 비교 |
| 평가 | rolling origin(학습 24개월 이상), WAPE·MASE, Diebold-Mariano(표본 한계 명시) |
| 불확실성 | 경험적·conformal 80·95% 구간, 실제 포함률, pinball loss |
| 구조 변화 | CUSUM·Chow, 학습 창 비교(전체 vs 정책 이후) |
| 표본 외 | 2026-09~11 예측(주 예측과 머신러닝 10종)을 데이터 공개 전에 SHA-256과 함께 고정, 공개 후 별도 파일로 채점(고정 파일은 수정 금지) |
| 선행 지표 | 한국 수출 통계를 이용한 nowcasting이 기준 예측보다 나은지 |

### 5.8 의사결정 (D1~D2)
- 리드타임을 신고 월 기준으로 나눠 정책 전후 중앙값·변동성 변화를 본다(Q5).
- 안전재고: SS = z·√(L·σ_d² + d²·σ_L²). 리드타임은 관측 분포, 수요 변동은 시나리오 범위. 동부 직송(해상) vs 서부 하역 + 내륙 운송을 재고 일수로 비교한다.
- 하역항 집중: LA·롱비치가 N일 멈출 때의 영향 물량과 대체 경로의 추가 리드타임.
- 민감도: 내륙 일수 × 내륙 일수 표준편차 × 수요 변동계수 × 서비스 수준 전체 조합에서 유리한 경로와 재고 일수 차이(`decision_route_sensitivity`).

### 5.8.1 최종 산출물: 주장·가정·권고
- `claims`: 결론마다 근거 수준(observed·estimated·scenario·hypothesis), 출처 표, 방법, 표본, 강건성, 인과 주장 허용 여부.
- `assumptions`: 공개 데이터가 관측하지 않는 입력값, 기준값·민감도 범위·결과에 미치는 영향.
- `decision_recommendations`: 결정별 조건, 권고, 근거 주장, 불확실성, 한계, 필요한 다음 데이터. 프로젝트의 최종 결과이며, 숫자는 모두 다른 결과 표에서 읽는다(`src/kbeauty/synthesis.py`).

### 5.9 합성 운영 데이터 검증 (부록)
- 공개 데이터를 기준값으로 만든 합성 주문·재고·선적 데이터(27개 표, 132만 행)를 해시·검사 219개·사전 가설 6개로 검증한다.
- 합성 데이터로는 "설계대로 만들어졌는가"만 판단하고, 시장에 대한 결론은 실제 데이터에서만 낸다.

## 6. 사전 등록

- 원인 검증(Q1~Q5)과 표본 외 예측(F3)은 데이터를 받기 전에 질문·지표·검정·판정 기준을 [`preregistration.md`](preregistration.md)에 적고 커밋한다. 커밋 시각이 증빙이다.
- 분석 중 달라진 점은 지우지 않고 사전 등록 문서의 변경 기록에 날짜와 이유를 남긴다.
- 사전 등록에 없던 분석(예: 진단, 강건성)은 그 사실을 밝히고 보조 결과로만 보고한다. 결과를 본 뒤 비교군·기준을 바꿔 유의성을 만들지 않는다.

## 7. 노트북 구성

분석은 단계별 노트북에서 진행한다. 계산 공식은 `src/kbeauty/` 패키지에 두고 단위 테스트로 검증하며, 노트북은 그 함수를 단계마다 호출해 중간 결과·진단을 보여 준다.

| 노트북 | 질문 | 내용 |
|---|---|---|
| `00_summary` | 전체 | 결론 먼저 쓰는 서사 노트북. 각 분석 노트북의 결론을 모은다 |
| `01_data_overview` | — | 원천별 구조, 결측·이상치, 국가·품목·운송수단 분포 |

| `03_cross_country` | Q1 | 국가 비교: 원자료 탐색 → 평행 추세 → 이중차분 → 위약 분포 → 다중비교·MDE → 합성 통제 진단 → 강건성 |
| `04_mirror` | Q2 | 한국 수출 대 미국 수입, 시차·기준 맞춤, 정책 전후 비율 변화 |

- 마지막 셀은 노트북 추정치와 `reports/tables`의 일치를 assert한다.
