# 사전 등록 — 원인 검증(Q1~Q5)과 표본 외 예측

작성 2026-11-02. 이 문서는 **국가 비교·한국 수출·환율 데이터를 받기 전에** 작성해 커밋한다. 커밋 시각이 사전 등록의 증빙이다.
분석 중 이 문서와 다르게 진행한 부분은 지우지 않고 맨 아래 "변경 기록"에 이유와 함께 남긴다.

지금까지 본 데이터: 한국산 Census 수입(2024-01~2026-08), 선박 관측치, 관세청 API 형식 확인용 2개월(2025-01, 2025-09)의 응답 구조(화장품 값은 집계하지 않음).

## 2. 비교 국가 선정 규칙 (결과를 보기 전 고정)

1. Census `imports/hs`에서 **2024년 연간 HS 3304 수입액** 기준 상위국을 내림차순으로 정렬한다.
2. 지역·경제권 합계(EU, OECD 등 집계 코드)와 한국을 제외한다.
3. 상위 **8개국**을 비교군으로 쓴다. 8위 경계에서 결측 월이 있는 국가는 다음 순위로 대체한다.
4. 선정 결과는 `warehouse/seeds/peer_countries.csv`에 저장하고, 이후 바꾸지 않는다.

품목 범위는 한국과 같은 HS 3303·3304·3305·3307, 기간은 2024-01~2026-08이다.

## 3. 정책 시점

- 공통 처리 시점: 2025-09(8/7 상호관세 재설정, 8/29 소액면세 전 국가 중단 이후 첫 완전한 달).
- 국가별로 처리 시점이 다른 정책(예: 중국·홍콩의 소액면세 조기 종료, 국가별 관세율)은 **공식 문서로 확인된 것만** `policy_events_by_country.csv`에 넣고, 이질적 처리 시점 분석은 보조 분석으로 둔다.

## 4. 다중비교와 검정력

- Q1의 5개 지표에 Holm 보정, 보조로 BH(FDR 10%)도 보고한다.
- 위약: (a) 시간 위약 — 다른 전환 월, (b) 국가 위약 — 비교국 각각을 처리군으로 가정. 둘을 결합한 순위 p를 함께 보고한다.
- 최소 검출 효과(MDE): 사전 기간 잔차의 분산으로 시뮬레이션해 80% 검정력에서 검출 가능한 효과 크기를 먼저 계산하고, 그보다 작은 추정치는 "검출 불가"로 쓴다.

## 5. 예측 고정 (표본 외 검증)

- 2026-11-02 시점 데이터(2026-08까지)로 **2026-09·10·11월** 예측을 만든다. 대상은 전체 수입 금액, 해상+항공 중량, 품목 4개(스킨케어·메이크업·헤어·기타) × 운송수단 2개(해상·항공)의 금액이다.
- 주 예측: 직전 값과 계절 ETS의 동일 가중 평균. 보조로 개별 모델 값도 저장한다. 근거는 기존 백테스트(1개월 앞 최선 = 직전 값, 3개월 앞 최선 = 계절 ETS)다.
- 예측 구간: 백테스트의 시점별 상대 오차 분포에서 구한 80% 경험적 구간.
- 예측 파일과 SHA-256을 커밋한다. Census가 해당 월을 공개하면 WAPE와 구간 포함 여부를 채점해 별도 파일로 추가한다. **고정 파일은 수정하지 않는다.**

## 6. 인과 주장의 수위

- Q1이 지지되어도 "정책과 시점이 일치하는 한국 특유의 변화"까지만 쓴다. 같은 시기의 다른 요인(미국 수요, 유통 채널, 환율)을 완전히 배제할 수 없기 때문이다.
